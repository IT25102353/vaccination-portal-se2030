Manage vaccine stock, appointments and dose records in one place.

OpenVaccine is a web portal for a vaccination programme. Staff can track vaccine batches and expiry dates, book appointments, record administered doses, manage centers and log adverse reactions.

What it covers

  • Vaccine Stock & InventoryBatches, quantities, expiry dates and storage locations.Open
  • AppointmentsBook and manage patient vaccination appointments.Open
  • Dose RecordsRecord administered doses and certificate numbers.Open
  • Vaccination CentersCenter details, contact numbers and daily capacity.Open
  • Adverse ReactionsLog and follow up on post-vaccination incidents.Open
  • ReportsSummaries of programme activity over a chosen period.Open

About this project

OpenVaccine is a first-year university project for SE2030, built to practise object-oriented design. It is written in Java with Spring Boot and Thymeleaf and stores its data in MySQL.

Each module follows the same layers: a model class, a repository, a service and a controller.
